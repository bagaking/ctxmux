# Feature Goal: Run one bounded ctxmux peer-performance cycle

Contract: `bagakit.feature-goal.v1`
Feature: `f-22aczwza9`
Convergence: `terminal`

## Prime Directive

Execute one pre-registered, budget-bounded performance cycle over genuinely
comparable ctxmux, tmux, and Zellij behavior. Preserve raw evidence and all
correctness boundaries, optimize only when measured value exceeds complexity,
and close with honest wins, ties, and losses.

## Protected Invariants

- Workloads, peers, versions, metrics, comparability, statistics, margins,
  resource limits, and time budget are fixed before candidate results.
- Correctness, security, reliability, or supported semantics are never weakened
  or reclassified to manufacture a win.
- Raw-byte encoding changes only after a frozen end-to-end ROI rule is met;
  otherwise retaining the current path is a successful measured decision.
- The Feature owns no Kernel correctness, release, activation, packaging,
  orchestration, terminal renderer, or speculative compatibility work.

## Convergence Contract

The cycle stops after the fixed harness, one bounded measure-optimize-remeasure
pass, independent reproduction, and a complete report. Universal peer wins are
an aspiration, not a completion condition.
