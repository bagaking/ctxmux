# Measured-round index

Meta: one row per `rNN-*.md` performance/correctness round writeup in this
directory. Purpose is the same closed loop [`casebook.md`](casebook.md) gives
external failures — a checkable disposition for every round — applied to this
repo's own measured rounds, which were otherwise unindexed and mostly orphaned
(13 of 23 had zero inbound references when this index was added).

How to read a row:

- **Disposition** — `SHIPPED` a change landed; `ROLLBACK` a change was applied
  then backed out; `REFUTED` a candidate/hypothesis was disproved with no code
  change; `PREREG` a pre-registration written before its result; `METHOD` a
  measurement/attribution round with no product change.
- **Guard** — `executable` if the round names a test, fixture, or pinned check
  that fails when its lesson is violated; `prose` if the writeup is the only
  record.
- **Retry** — `⛔ do not retry` marks a path that was tried and rejected or
  rolled back (or a hard dead end a refutation established). These are the rows
  whose whole value is stopping a re-attempt.

The numbering runs r11–r28 with **no r15** (confirmed absent: r15 was never
authored in this directory). r11 has four writeups; r26/r27/r28 have two each.
